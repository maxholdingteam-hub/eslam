# ماكس ديزاين: من الموقع للمفتاح (ريلز وكاروسيل)

الصيغة: صورة موقع بناء خام، يترسم فوقها التصميم بخطوط بيضاء، وبعدين الغرفة تبني نفسها من الرسمة. هذي نفس فكرة الريفرنس (رسمة التصميم فوق المكان قبل التشطيب).

كل الصور والفيديوهات **مولّدة بالذكاء الاصطناعي، ومو من مشاريع منفّذة**، فعليها كلمة «تصميم مفاهيمي». خلّوها، ولا تكتبون إنها مشاريعنا.

- **الغلاف:** اختاروا فريم الرسمة (الخطوط البيضاء فوق الموقع)، لأنه أكثر شي يوقف السكرول.

## الجدول المقترح

ريل في اليوم، وبعده بيومين الكاروسيل حق نفس الغرفة: المجلس، بعدين الصالة، بعدين غرفة النوم.

## تعديل

- **الكلام اللي فوق الفيديو والصور:** في `source/overlays.html`. بعد التعديل شغّلوا:

```bash
cd source && node overlays.js && python3 posts.py
```

- **الريلز:** تُعاد بأمر لكل غرفة:

```bash
source/reel.sh s1
```

- **ملفات المصدر:** الصور والكليبات المولّدة في `gen/`.
