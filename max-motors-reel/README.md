# ريل ماكس موتورز — موقع ثلاثي الأبعاد على لابتوب

نفس فكرة ريلز "POV + أداة + AI = 🤯": موقع ثلاثي الأبعاد بيتعمله سكرول على شاشة لابتوب، وفوقه هوك ومعادلة ودعوة للتعليق.

```
max-motors-reel/
├── site/index.html     ← الموقع ثلاثي الأبعاد (three.js) — يشتغل لوحده كصفحة حقيقية بالسكرول
├── reel/reel.html      ← تكوين الريل 1080×1920: الخلفية، الهوك، المعادلة، اللابتوب، الـ CTA
├── render.cjs          ← يصوّر الريل فريم فريم ويطلّع MP4
├── fonts/              ← Cairo + Tajawal
├── audio/intro.mp3     ← مؤثر صوتي قصير في البداية
└── out/                ← الناتج (max-motors-reel.mp4 + صور المعاينة)
```

## تغيير النصوص

في أول `reel/reel.html` فيه `CONFIG`:

```js
hook:   'POV: لقيت سيارة أحلامك بالذكاء الاصطناعي',
labelA: 'ماكس موتورز',
labelB: 'AI',
cta:    'اكتب <b>«ماكس»</b> في التعليقات',
url:    'maxmotors.sa',
```

نصوص الموقع نفسه (العناوين والأقسام) موجودة في `site/index.html`.
وألوان السيارة في `PAINTS`، وحركة الكاميرا في `CAM`.

## الريندر

محتاج Node وPlaywright (Chromium) وffmpeg:

```bash
node render.cjs --preview 0,4,8,11,14   # صور معاينة في out/preview
node render.cjs                         # الفيديو الكامل في out/max-motors-reel.mp4
```

عشان تشوف الموقع بنفسك وتعمله سكرول: `npx http-server .` وبعدين افتح `/site/index.html`.
