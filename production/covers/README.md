# نظام الكفرات الموحّد — ماكس موتورز

كل فيديو جديد ياخد كفر بنفس القالب، علشان الجريد يبان هوية واحدة.

## القالب (1080×1920)
- فوق: لقطة من الفيديو نفسه (السيارة أو المقدّم كامل، بدون نص مقصوص) — 0 إلى 1200px.
- خط ذهبي رفيع ثابت عند 1215px.
- بادج نوع المحتوى (إطار ذهبي): **نختصرها لك** · **إعلان** · **تحدي** · **ترند**.
- عنوان أبيض كبير Tajawal 900، وكلمة واحدة بالذهبي `<b>`.
- لوجو ماكس موتورز صغير تحت.
- كل المهم داخل المنطقة الوسطى 3:4 (من 240 إلى 1680px) اللي تبان في جريد تيك توك وانستجرام.

## إضافة كفر
1. استخرج لقطة: `ffmpeg -ss <ثانية> -i video.mp4 -frames:v 1 src/<n>.jpg`
2. أضف سطر في `covers.json`: `img`, `top` (إزاحة القص؛ الظاهر في الجريد = الفريم من top+240 إلى top+1200), `cat`, `title`, `slug`.
3. `python3 -m http.server 8790` من هذا المجلد، ثم `node shoot.js` → `out_<n>.jpg`.

ممنوع: اسم المقدّم في أي لقطة (التاج القديم أعلى حلقات السلسلة القديمة).
