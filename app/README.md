# تطبيق ماكس موتورز (PWA)

تطبيق ويب يتثبّت على الجوال (أيقونة على الشاشة) — نفس الكود ينفع بعدين لتطبيقات المتاجر.

## الصفحات
- الرئيسية: بحث، أنواع السيارات، الماركات، مختارات، بانر الشركات
- السيارات: بحث + فلترة بالنوع والماركة
- صفحة السيارة: صور، مواصفات، وصف، «اطلبها: كاش أو تمويل»، اتصال، مشاركة، مفضلة
- المفضلة (محفوظة على الجهاز)
- الشركات: نموذج طلب أسطول
- تواصل: الرقم الموحد، الفروع، سياسة الخصوصية

## الإعدادات — `config.js`
- `whatsapp`: رقم واتساب يستقبل الطلبات (مثال 9665XXXXXXXX). لو فاضي يتحوّل الطلب لاتصال.
- `leadEndpoint`: رابط يستقبل الطلبات JSON (المرحلة الجاية: Supabase + لوحة تحكم).
- `branches`: الفروع ومواعيدها وروابط الخريطة.

## تحديث السيارات
بعد إضافة سيارة في `MaxMotors_Site_Listings/<Brand>/<Model>` (صور + `بيانات_السيارة.txt`):
```
python3 app/tools/build_data.py
```
يبني `data/cars.json` وصور WebP خفيفة. السعر يُحذف تلقائيًا (لا أسعار ولا عروض).

## تشغيل محلي
```
cd app && python3 -m http.server 8765   # ثم افتح http://localhost:8765
```

## النشر
أي استضافة ملفات ثابتة (Cloudflare Pages / Netlify / Vercel — مجانية): ارفع مجلد `app/` كما هو. لازم HTTPS علشان يتثبّت كتطبيق.
