# ظلال القاهرة ١٨٠٥: نسخة Unreal Engine 5

مشروع Unreal Engine 5.4 بلغة C++. كل أنظمة اللعب مكتوبة بالكود، والشكل الواقعي (الشخصيات والمباني والحركة) بيتركّب من أصول جاهزة جوه المحرر.

## الأنظمة الجاهزة في الكود

| الملف | بيعمل إيه |
|---|---|
| `CairoPlayerCharacter` | يوسف: كاميرا من ورا الكتف، جري، تسلق أي حيطة، طلوع على الأسطح، قتال (ضربة سريعة وتقيلة وكومبو)، صد، تفادي، اغتيال، اغتيال جوي، إعدام، شيل الجثث، عين الصقر، تبطيء الصورة، ووقعة بتعوّر لو عالية |
| `GuardCharacter` + `GuardAIController` | الحراس: دورية، عداد اكتشاف، شك، مطاردة، قتال (ضربة برتقالي تتصد وحمرا تتفادى)، توازن وترنّح، تفتيش الجثث والقش، ورماة بيضربوا سهام |
| `GuardCharacter` (الاختيار `bIsTarget`) | حسن آغا: بيلف على الدكاكين، ولو حس بيك بيجري على باب القلعة |
| `CivilianCharacter` | الأهالي: بيتمشوا، ويقفوا عند الدكاكين، ويجروا ويصرخوا لو حصل قتل، وتقدر تستخبى وسطهم |
| `HidingSpot` | عربية القش: تستخبى فيها، وتنزل فيها من أي ارتفاع |
| `ViewPoint` | فوق المئذنة: مزامنة وقفزة الإيمان |
| `SafehouseZone` | البيت الآمن: نهاية المهمة |
| `CairoGameMode` | منطق المهمة، والشهود، والفوز والخسارة |
| `CairoHUDWidget` | أساس الواجهة: بار الصحة، والطاقة، والحالة، والمهمة، وزرار الفعل |

**التحكم:** متعمول من الكود، ومش محتاج تعمل ملفات إدخال. `WASD` للحركة، والماوس للكاميرا، و`Shift` للجري، و`Space` للنط، والكليك ضربة والكليك اليمين ضربة تقيلة، و`Q` للصد، و`C` للتفادي، و`F` للاغتيال والإعدام وشيل الجثة، و`V` لعين الصقر. ودراع الإكس بوكس أو البلايستيشن شغال كمان.

> الكود ده لسه **ما اتبناش (compile) على جهاز فيه Unreal**، لأنه اتكتب في بيئة مفيهاش المحرك. أول بناء ممكن يطلع أخطاء صغيرة وهصلحها.

## ١. البرامج المطلوبة (مرة واحدة)

**الجهاز:** ويندوز ١٠ أو ١١، وكارت شاشة RTX 2060 أو أحسن، و١٦ جيجا رام (و٣٢ أحسن)، ومساحة فاضية حوالي ١٥٠ جيجا على SSD.

1. **Epic Games Launcher**: نزّله من epicgames.com واعمل حساب.
2. من اللانشر: **Unreal Engine** ← Library ← **Install 5.4**.
3. **Visual Studio 2022 Community** (مجاني). وقت التسطيب اختار:
   - Game development with C++
   - Desktop development with C++
   - من التفاصيل: Windows 10/11 SDK، و.NET Framework 4.8 SDK
4. **Git** (اختياري): عشان تنزّل المشروع من GitHub.

## ٢. فتح المشروع

1. نزّل الفولدر `cairo-unreal` على جهازك.
2. كليك يمين على `CairoShadows.uproject` ← **Generate Visual Studio project files**.
3. دبل كليك على `CairoShadows.uproject`. هيسألك تبني الموديول، قوله **Yes**. أول مرة بتاخد وقت.
4. لو طلع خطأ في البناء، ابعتلي الرسالة اللي ظهرت وأنا أصلحها.

## ٤. تجهيز المرحلة (أول مرة)

1. اعمل Level جديد، وحط فيه **NavMeshBoundsVolume** يغطي الشوارع (من غيره الحراس مش هيتحركوا).
2. اعمل **Blueprint** من كل كلاس واختار الموديل والأنيميشن:
   - `BP_Youssef` من `CairoPlayerCharacter`، وحط المونتاجات في قسم Cairo|Anim
   - `BP_Janissary` و`BP_Archer` (فعّل `bIsArcher`) و`BP_HassanAgha` (فعّل `bIsTarget`) من `GuardCharacter`
   - `BP_Civilian` من `CivilianCharacter`
   - `BP_GameMode` من `CairoGameMode`، وخلّي Default Pawn يبقى `BP_Youssef`
3. حط **Target Points** للدورية، واختارها في `PatrolPoints` لكل حارس.
4. حط `HidingSpot` جنب الحيطان، و`ViewPoint` فوق المئذنة واختار له عربية القش في `LeapTarget`.
5. حط `SafehouseZone` قدام باب البيت الآمن، وأي Actor عند باب القلعة وحط عليه Tag اسمه `CitadelGate`.
6. اعمل **Widget Blueprint** من `CairoHUDWidget`، واربط البارات بالدوال (GetHealthPercent وغيرها)، وحطه في `HUDWidgetClass` في `BP_Youssef`.
