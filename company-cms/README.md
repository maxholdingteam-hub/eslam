# Company CMS

بورتفوليو شركة احترافي (عربي / إنجليزي) + لوحة تحكم بتعرّفك مين فتح البورتفوليو وعمل إيه. شغّال على Cloudflare على دومين الشركة.

- **الموقع**: `https://company.com`
- **لوحة التحكم**: `https://company.com/admin`
- **لينك متتبع لعميل**: `https://company.com/v/alrajhi`

## لوحة التحكم

| القسم | بيعمل إيه |
|---|---|
| الرئيسية | الزيارات، عدد الأشخاص، متوسط الوقت، نسبة اللي وصلوا لآخر الصفحة، ضغطات واتساب والاتصال، المدن، جايين منين، الأقسام اللي اتشافت، آخر الزيارات |
| سجل الزيارات | كل زيارة: الوقت، اللينك (لو متتبع)، المدينة، الجهاز، المدة، نزل لحد فين، شاف أنهي أقسام، ضغط على إيه، بعت طلب ولا لأ، وهل راجع تاني |
| اللينكات المتتبعة | تعمل لينك لكل عميل (مثلاً «شركة الراجحي»)، تنسخه أو تبعته واتساب، وتشوف فتحه كام مرة وإمتى وقعد قد إيه |
| طلبات العملاء | طلبات عرض السعر من الموقع، مع حالة (جديد / اتواصلنا / اتقفل بيع / مكملش) ومن أنهي لينك جه |
| تعديل الموقع | كل المحتوى بالعربي والإنجليزي: الشركة، الأرقام، من نحن، الخدمات، المشاريع بالصور، طريقة العمل، العملاء، الآراء، الفريق، التواصل، الألوان وجوجل |
| استيراد من البروفايل | ترفع بروفايل الشركة PDF والذكاء الاصطناعي يملا الموقع باللغتين |
| الصور والملفات | رفع الصور واللوجوهات وملفات PDF |
| النسخ السابقة | الرجوع لأي نسخة من آخر 30 حفظ |
| المستخدمين | مدير (كل حاجة)، محرر (المحتوى واللينكات)، مشاهد (الإحصائيات بس) |

### «مين دخل» بالظبط؟

- **العميل اللي فتح لينك متتبع**: بيظهر باسمه (الاسم اللي انت كتبته للينك)، ومعاه كل نشاطه، وتقدر يوصلك تنبيه تيليجرام أول ما يفتح.
- **اللي بعت طلب من الفورم**: بيظهر باسمه ورقمه.
- **الزائر العادي**: بيظهر كـ «زائر» بالمدينة والجهاز ومصدر الزيارة. محدش يقدر يعرف اسمه، ومش بنخزّن IP.

## الرفع على Cloudflare

محتاج حساب Cloudflare (مجاني) ودومين الشركة متضاف لـ Cloudflare (Add a domain، وتغيّر الـ nameservers عند الجهة اللي اشتريت منها الدومين).

```bash
cd company-cms
npm install
npx wrangler login
```

```bash
npx wrangler d1 create company
```

انسخ الـ `database_id` وحطه في `wrangler.jsonc` مكان `REPLACE_WITH_D1_ID`.

```bash
npx wrangler r2 bucket create company-media
```

```bash
npm run db:init:remote
```

```bash
npx wrangler secret put ADMIN_PASSWORD
```

(باسورد أول دخول. اسم المستخدم: `admin`. بعد كده تقدر تغيّره وتضيف مستخدمين من اللوحة.)

```bash
npx wrangler secret put ANTHROPIC_API_KEY
```

(اختياري، لـ «استيراد من البروفايل».)

```bash
npm run deploy
```

بعدها: Workers & Pages > `company-cms` > Settings > Domains & Routes > Add > Custom domain > دومين الشركة (و `www`).

### تنبيهات تيليجرام (اختياري)

1. في تيليجرام كلّم `@BotFather` واعمل بوت جديد، وخد الـ token.
2. ابعت أي رسالة للبوت، وبعدين افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخد رقم `chat.id`.
3. احفظهم على السيرفر:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
```

```bash
npx wrangler secret put TELEGRAM_CHAT_ID
```

ومن لوحة التحكم > حسابي > «ابعت رسالة تجربة».

## الأمان والخصوصية

- باسوردات المستخدمين متخزنة بـ PBKDF2 (مش نص عادي)، والجلسة كوكي `HttpOnly` و `SameSite=Strict`.
- حماية من تخمين الباسورد ومن السبام في الفورم، وكل الطلبات اللي بتعدّل لازم تيجي من اللوحة نفسها.
- زيارات فريق الشركة (وهما مسجلين دخول) والبوتات مش بتتحسب.
- مفيش IP بيتخزن ومفيش كوكيز تتبع. الزائر بياخد رقم عشوائي على جهازه بس عشان نعرف لو رجع تاني.
